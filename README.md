# Overview
This is a quick music organiser I made to sort through my local audio/music files.

It takes an unstructured music folder, and organises it by artist, and album.

It also supports in-folder artist and album art.

# Improvements
I already have several planned improvements for this program, mostly focusing on readability, comments, and general code improvements.

# How files are organised
```
root_folder\
    ├─ artist.ext
    └─ album\
        ├─ cover.ext
        └─ audio_file.ext
```

# How to use
You can download and extract the latest version from the github releases.
